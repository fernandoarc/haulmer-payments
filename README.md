# Haulmer.Payments

Payment processing service built with .NET 8, SQL Server and EF Core Code First.

## Solution structure

- `src/Haulmer.Payments.Api`: API entrypoint
- `src/Haulmer.Payments.Application`: use cases and application logic
- `src/Haulmer.Payments.Domain`: domain model
- `src/Haulmer.Payments.Infrastructure`: persistence and external integrations
- `tests/Haulmer.Payments.UnitTests`: unit tests

## Tech stack

- .NET 8
- ASP.NET Core Web API
- SQL Server
- EF Core
- Docker
